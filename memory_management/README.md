# 内存管理模拟系统

这是一个用Python实现的内存管理模拟系统，包括动态分区管理和动态分页管理两个主要功能。

## 功能特点

### 动态分区管理
- 支持三种分配算法：首次适应、最佳适应和最坏适应
- 可视化显示内存分区状态
- 支持内存分配和释放操作
- 自动合并相邻空闲分区

### 动态分页管理
- 实现请求式分页管理
- FIFO页面置换算法
- 可视化显示页表状态
- 支持内存读写操作
- 实时显示访问日志

## 系统要求
- Python 3.6+
- tkinter 8.6+

## 安装步骤
1. 克隆或下载本项目
2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 运行方法
在项目根目录下执行：
```bash
python src/main.py
```

## 使用说明

### 动态分区管理
1. 在"作业名称"输入框中输入作业名
2. 在"作业大小"输入框中输入所需内存大小（KB）
3. 选择分配算法（首次适应/最佳适应/最坏适应）
4. 点击"分配内存"按钮进行分配
5. 要释放内存时，输入作业名称后点击"释放内存"按钮

### 动态分页管理
1. 在"页号"输入框中输入要访问的页面号
2. 在"页内偏移"输入框中输入页内偏移地址
3. 选择操作类型（读取/写入）
4. 点击"访问内存"按钮执行操作
5. 在下方可查看页表状态和访问日志

## 注意事项
- 所有输入的数值必须为非负整数
- 页号范围：0-6
- 页内偏移范围：0-1023
- 作业大小单位为KB
